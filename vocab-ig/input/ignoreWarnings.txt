== Suppressed Messages ==

# Designation languages cannot be validated without a working terminology
# server. This guide carries 1,061 designations inherited from THO -- German
# translations, mostly -- each with a `language` of `de` or similar. FHIR binds
# designation.language to http://hl7.org/fhir/ValueSet/all-languages, which
# includes the system urn:ietf:bcp:47. No package defines that system's codes,
# so the validator has to ask a terminology server, and https://tx.fhir.org/r5
# answers with a cache error on every request. That is 3,267 errors -- three
# per designation -- against roughly 212 of every other kind, which buries
# everything worth reading. The designations are correct: `de` is a valid
# BCP 47 tag and THO publishes exactly these values. Dropping them instead is
# not an option; they are content THO already publishes at these canonicals,
# and deleting them is what this guide's merge with THO exists to prevent.
# Revisit when the terminology server is reachable again. Scoped to the
# all-languages value set alone, so a language problem that is not this one
# still surfaces.
%http://hl7.org/fhir/ValueSet/all-languages%
